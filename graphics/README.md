# EPsych2 graphics package — Instrument theme

Proposal assets. Nothing here is installed in the repository yet.

Accent #1f6f8b · secondary #b5652f · ground #eef2f5 · ink #0f202b
Type: Figtree (ExtraBold headings / Regular body). Icons on a 24px grid, stroke 2.75.

## Files

- `banner.png` — wiki home banner, 1280x320 (@2x)
- `workflow-diagram.png` — experimenter workflow: design -> configure -> run -> analyze
- `architecture-diagram.png` — GUIs / epsych core / stimgen / psychophysics / hw.Interface
- `logo.svg`, `favicon.svg` — the mark (same asset)
- `png/logo-{512,128,64,32,16}.png` — raster mark
- `icons/*.svg` — ten doc-section icons: install, protocol-design, run-session, calibration,
  stimulus-generation, hardware, trial-selection, analysis, box-gui, data-saving

## Notes

Diagrams are PNG renders of the live layout; re-render at any size from the source design.
Icons are single-color and can be recolored by editing the stroke value.
